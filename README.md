# CO-lines-for-SIMBA-galaxies
Here, I present the estimation of CO lines for galaxies from SIMBA galaxies using DESPOTIC and SLICK.

I prepared it to use in SLURM-like cluster in my institute. Thus, I needed to modify some of the SLICK implementation. 
The modified files are given in the SLICK directory. For the original implementation look for Karolina Garcia's paper or github (be aware there is a typo in limfunctions.py SLICK).

Everything else is written by me.
